Dirac captures.
Repeatable HeSuVi extraction.

Use the original stimulus and a trusted stereo reference to align a target capture, inspect the timing, and export a 14-channel impulse response.

No AI inference. No EQ. No per-ear alignment. No silent resampling.

This is a documentation baseline. Audio processing runs locally through the command line. Select local WAVs below to inspect their headers and download a config. Audio stays on your device; conversion still runs in Python.

Three inputs

01 / Source

Original Dirac stimulus

Eight-channel 7.1 WAV. Exactly one impulse per channel, including LFE. Verified channel mask or an explicit verified map when metadata is absent.

02 / Reference

Trusted stereo reference

The same stimulus, with its reference time origin already established. This recording stays at shift zero.

03 / Target

Raw stereo capture

All eight events in the same chronological order, at the same sample rate. Enough leading and trailing audio for analysis and extraction.

Setup

Use Python 3.10 or newer. From the repository folder, create and activate a virtual environment, then install and test.

python -m venv .venv
# Windows PowerShell:
.venv\Scripts\Activate.ps1
# macOS / Linux:
source .venv/bin/activate

python -m pip install -e .
python -m unittest -v test_dirac_to_hesuvi

Run the activation command for your shell only. If PowerShell blocks activation, use .venv\Scripts\python.exe directly; no execution-policy change is needed.

Inspect first. Export second.

  1. Copy config.json to config.local.json.
  2. Set stimulus, apple and capture to your local WAV paths. Relative paths resolve beside the config.
  3. Choose a fresh output_dir. Review sample-based window lengths for your sample rate.
  4. Run a dry run and inspect qa.json, events.csv, candidate detections and the onset plot.
  5. Export only after the diagnostics support the alignment.
hesuvi-auto-editor --config config.local.json --dry-run
hesuvi-auto-editor --config config.local.json

Direct-script alternative: python dirac_to_hesuvi.py --config config.local.json. Add --dry-run for diagnostics without audio export.

Output

Fourteen-channel float32 WAVs at the input sample rate. Each whole file receives one scalar gain to −2 dBFS peak. LFE is checked but excluded. Apple and Far are the historical output labels for the reference and target.

Timing has limits

  • Default peak alignment is a calibration convention. It does not identify physical arrival time or separate recording-start delay from renderer latency.
  • An earlier substantial feature can reject an ambiguous strongest peak. Weaker or closely spaced features remain unresolved.
  • There is no clock-drift correction. Mismatched rates, missing events and inconsistent timing fail checks.
  • Cropping changes the response. Review omitted energy and retain the originals. Prefix archives are not standalone presets; prepending them adds latency.
  • A failed run can leave older audio in its output directory. Use a fresh directory and inspect the latest result.

No recordings or generated presets are included. Diagnostics contain local paths and source hashes; keep them private.

    About the calibration

    Edited HRIR alignment

    Select Edited HeSuVi HRIR for a 14-channel WAV already in HeSuVi order. The included Apple reference loads automatically. The editor measures the seven directional pair peaks in both files and applies one common integer shift. It retains the complete tail, pads with silence when required, and applies one common gain to reach −2 dBFS. Leading samples below ten times the greater of the input and reference noise floors are treated as noise. Larger samples trigger a warning with an explicit option to continue. The threshold has a −120 dBFS floor after the tenfold multiplier; removed levels and any override are recorded in the report. Cropping cannot restore samples already removed by earlier editing.

    Reference analysis

    The Apple reference and original 7.1 Dirac stimulus load automatically from this app. Processing verifies the stimulus and measures the seven directional pair peaks in the actual Apple WAV each time. Both files are included in the standalone package and can be downloaded under Reference files.

    Recording and timing

    Use the complete, unedited stereo capture of the supplied eight-event 7.1 Dirac stimulus, including LFE. Missing events, clipping, silence, schedule mismatch, ambiguous earlier responses, and above-threshold tail truncation produce errors.

    One timing shift applies to every direction and both ears. The Apple reference has a measured median directional pair peak of 53 samples. Individual direction and ear delays are retained. This is an operational timing convention: identical impulses cannot verify speaker routing or distinguish capture-start delay from renderer latency.

    The output contains seven stereo pairs in HeSuVi channel order. LFE is checked and excluded. One common gain sets the highest sample to -2 dBFS while preserving relative levels and ear timing.

    Advanced settings

    Leave extraction length at its reference defaults for normal use: 0 pre-roll samples and 24,000 response samples (500 ms). Timing is detected automatically; response length is fixed by the reference conversion.

    Enable Override extraction length only when you need a different crop. Pre-roll retains samples before the calibrated origin. Response length retains samples from that origin onward. At 48 kHz, 48 samples = 1 ms; their total must not exceed 48,000 samples. At zero pre-roll, a separate 1024-sample negative-time prefix WAV preserves earlier samples using the main gain. It is for reconstruction rather than HeSuVi playback. A nonzero prefix outside that archive, an omitted peak, or tail activity above the noise threshold produces an error. Increase pre-roll or response length as directed; inspect the full response before shortening it.

    Local use

    Recordings are processed in your browser and are never uploaded. The downloaded report contains the recording filename, SHA-256 hash, processing details, and channel statistics.

    For the standalone package, extract the ZIP and run Launch.cmd on Windows, or python3 launch.py on other platforms. Python 3 is required for the local server. Keep its terminal open while using the app. Opening index.html directly with file:// prevents the processing worker from starting; use the launcher or this HTTPS website.
